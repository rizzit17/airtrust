Calibration uses only the first 10% of the year, before training. Unseen stations never contribute to calibration or learning.

Client calibration & aggregation

Confidence = max(exp(−calibration RMSE / 35), 0.05). Aggregation weight ∝ training samples × confidence.

Validation convergence

First seed · graph models · checkpoint selected using validation RMSE. The test period is never used to select checkpoints.

Evaluation boundaries

EMPIRICAL PRIVACY ASSESSMENT

Local data. Measurable leakage.

An honest-but-curious aggregator observes individual client updates. The probe tests whether the update reduces a training window’s loss more than a reserved nonmember window’s loss.

Update-based membership inference

How to interpret the probe

AUC of 0.5 corresponds to random ranking. Higher AUC means the specified attack distinguishes members more reliably. Advantage is the maximum true-positive rate minus false-positive rate over thresholds.

Nonmembers are randomly reserved from the training era and never optimized on. Temporal windows can overlap, so correlated samples limit the strength of the privacy conclusion.

THREAT MODEL

Federation alone
doesn’t certify privacy.

Raw training records are absent from the aggregation interface. Model updates can still leak information. This experiment includes neither secure aggregation nor a differential privacy guarantee.

Next steps: evaluate secure aggregation, client-level clipping and noise, and stronger attacks under matched assumptions.

Preprocessing & source distinctions

Negative or above-2000 µg/m³ PM2.5 values are excluded. Stations require at least 70% valid hourly coverage. Input gaps are forward-filled for at most three hours; reference labels remain unimputed. Time is local to each city. Simulation parameters are explicit scenario assumptions.

OpenAQ and sensor.community were candidate sources in the proposal. They are not claimed as datasets used in this implementation. Beijing is retained with an independent persistence benchmark; this does not establish cross-city federated transfer.
